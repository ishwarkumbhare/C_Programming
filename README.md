## ▶️ How to Run a Program

1. Install a C compiler such as GCC.
2. Open the terminal in the folder containing the C file.
3. Compile the program:

   `gcc program1_1.c -o program1_1`

4. Run the program on Windows:

   `.\program1_1.exe`
